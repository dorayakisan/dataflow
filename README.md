# DataFlow Ver. 1.4

**公開デモ：[DataFlowを試す](https://dorayakisan-dataflow.streamlit.app/)**

サイドバーの「サンプルデータを読み込む」から、架空の500明細で分析を体験できます。

売上ファイルの確認から、返品を含む集計、Excelレポートの作成までを一つの画面で行う業務用Webアプリです。Pythonを活用したデータ整理・集計業務のポートフォリオとして利用できます。

## 主な機能

- CSV・Excelを最大10ファイル統合。ファイルごとのシート選択・列の対応付け
- 必須項目、数値、日付、割引、返品、重複候補の検証
- 行単位の修正・除外・警告確認と再検証。元の入力値は別に保持
- 純売上・数量・取引件数など6つのKPIと、日別・月別・商品別・カテゴリ別の分析
- フィルタに即時連動するダッシュボード
- 修正前データと検証結果を含む5シートのExcel、編集可能なExcelグラフ
- 固定シードの架空サンプル500明細（複数商品を含む会計、全額・部分・複数回返品、キャンセル）

## 技術・プロジェクト構成

Python 3.10～3.12、Streamlit、pandas、openpyxl、Plotly、pytestを使用します。動作確認はPython 3.10で実施。公開にはPython 3.12を選択できます。直接依存はrequirements.txtで固定しています。

```text
app.py                 日本語UI・セッション制御
dataflow/ingest.py      入力検証・列マッピング・統合
dataflow/engine.py      正規化・検証・売上台帳
dataflow/analysis.py    フィルタ・KPI・集計
dataflow/export.py      Excel出力
dataflow/sample.py      再現可能なサンプル生成
sample_data/            アップロード用CSV・Excel
tests/                 計算・入出力・画面の自動テスト
.streamlit/config.toml 配色・アップロード制限
```

## ローカルで起動

このフォルダをターミナルで開いて実行します。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS/Linuxでは `.venv\Scripts\python` を `.venv/bin/python` に置き換えます。ブラウザで表示されたローカルURLを開きます。

## 画面と使い方

1. サイドバーで「サンプルデータを読み込む」を押すか、ファイルを選択します。
2. アップロードでは各ファイルのシート・列の対応付けを確認し、「対応付けを確定して読み込む」を押します。失敗したファイルは理由を表示し、読めたファイルのみ統合します。読み直すと編集内容は新しい入力に置き換わります。
3. **データ確認**タブで問題を修正します。「除外」で行を外せます。警告行は内容を確認したうえで「警告確認」を選択します。重複候補も自動削除しません。
4. 「編集を確定して再検証」を押すと、修正を反映して全返品を再計算します。エラー行・未確認の警告行は集計しません。除外行の問題も監査用に表示する場合があります。
5. **ダッシュボード**と**集計表**はサイドバーの日付・商品・カテゴリで即時更新します。選択を空にした商品・カテゴリは0件になります。再検証やデータ交換時はフィルタを初期化します。
6. **エクスポート**で全データかフィルタ結果を選び、名前を編集し、生成後にダウンロードします。

入力と確認状態はセッションに保存し、フィルタを触っても編集表の未確定入力を保持します。ブラウザの再接続やサーバー再起動をまたぐ保存は保証しません。「セッションのデータを消去」でアプリの保持状態を消せます。

## 対応ファイル・項目

CSV（UTF-8、BOM付きUTF-8、CP932、Shift_JIS）と `.xlsx` に対応。見出しは先頭行、重複・空欄のない列名を指定してください。CSVはカンマ区切り、空行や列数不一致は修正してから読み込みます。Excelは1ファイルにつき選択した1シートを読み込みます。

|項目|必須|未指定の場合|
|---|---|---|
|日付|はい|エラー|
|商品名|はい|エラー|
|数量|はい|エラー|
|単価|はい|エラー|
|カテゴリ|いいえ|未分類|
|割引金額|いいえ|0|
|取引区分|いいえ|通常販売|
|取引ID・元取引ID|いいえ|空欄|

数量は0より大きい正数、単価・割引は0以上。返品も数量・単価・割引を正数で入力します。数値はカンマ区切りに対応します。数値の上限は1兆、入力長は30文字です。

日付は年/月/日、年-月-日、年.月.日、年月日、YYYYMMDDなどを認識します。`01/02/2026` は自動確定せず、行の「日付解釈」で「月/日」または「日/月」を選択します。集計処理が扱う日付範囲は1678年～2261年です。Excelの日付セルも読み込めます。Excelの数値だけのシリアル日付は日付セル形式に直してください。

## 計算ルール・判断が必要なケース

通常販売は `数量 × 単価 − 割引金額` をDecimalで計算し、明細ごとにROUND_HALF_UPで整数円に確定してから合計します。数量は小数にも対応します。入力値の小数点の位置は100桁以内、台帳計算は160桁精度に設定し、長い小数でも円単位への丸め前の精度を確保します。

元取引IDがある返品は、検証済み・集計対象の通常販売を取引IDと商品名で検索します。同一商品が複数明細にあるときは、自動で割り当てずエラーにします。元販売の行IDを返品行の「元明細ID」に入力すると一意に指定できます。明示指定では元販売の商品名・カテゴリを優先します。返品日は元販売日以降とします。

部分返品は元販売の確定済み円金額を数量比で配分します。複数回返品は返品日・行ID順に処理し、数量超過・返金超過を拒否します。最終返品では残額を返し、全数量返品時に元の売上額と一致させます。小額の売上を多数の部分返品に分割すると丸めにより最終返品前に返金上限へ達することがあり、上限を超える行は修正が必要です。

元取引IDが空、元販売が見つからない、または商品が一致しない返品は警告とし、確認後のみ返品行の数量・単価・割引から返金を計算します。この場合、元販売の数量・返金上限は照合できません。元販売がエラー・除外・未確認の場合も見つからない扱いになるため、先に販売側を解決してください。

重複は正規化した対象9項目の一致で候補にします。同じ取引IDで商品・数量・単価などが違う明細は重複にしません。同一会計内の同内容明細を区別する明細IDがないため、候補は人が確認します。確認済みでも警告履歴は残ります。

純売上＝販売売上−返品額、純数量＝販売数量−返品数量。返品は返品日にマイナス計上します。販売取引件数は販売の取引IDのユニーク数＋ID空欄の行数です。キャンセルも同じ件数ルールで別集計し、売上・数量・販売件数に含めません。平均単価＝純売上÷純数量で、数量0は算出不可。画面の平均単価だけ表示時に整数円へ丸めます。

返品額を全データで確定した後、計上日・正規化後の商品とカテゴリで絞り込みます。返品日だけの期間では純売上・数量が負になる場合があります。円グラフは正の純売上カテゴリだけを対象とし、0以下のカテゴリも集計表では表示します。

## Excelレポート

「元データ」「サマリー」「日別・月別集計」「商品別・カテゴリ別集計」「グラフ」の5シートを作成します。元データは対象範囲内の全行を含み、除外・集計対象・検証結果・修正前の値・修正有無を確認できます。「元データ」は監査用の正規化済み台帳で、アップロード前ファイルのバイナリ複製ではありません。現在のフィルタ結果では日付不正行など範囲判定できない行が除かれます。

グラフは画像ではなくopenpyxlのネイティブグラフです。対応するExcelで系列やデザインを編集できます。取引IDなどの文字列は文字列セルとして保存し、`= + - @` で始まっても数式にしません。XMLに使えない制御文字は除去、Excelのセル長上限を超える文字列は32,767文字で切り詰めます。金額台帳の計算は整数円ですが、Excel数値の有効桁数には制限があります。極端に大きな値はExcel上で精度が落ちる可能性があります。

## サンプルデータ

## セキュリティと運用上の注意

アップロードはサーバーへ送られます。個人情報・機密情報を公開デモへ送信しないでください。アプリは入力・出力データをディスクや共有キャッシュへ保存せず、セッションごとに保持します。ただし、ホスティング基盤やブラウザ側の保存を制御するものではありません。ログイン機能はありません。

入力は10ファイル、各10MiB、各20,000行・80列、統合50,000行まで。ExcelのZIP展開合計は80MiB、ZIP項目数は2,000以下です。破損・暗号化ファイルは拒否し、数式セルは値への変換を案内します。入力文字列をコードとして実行しません。予期しない入力・出力エラーは内部パスを含まない案内を表示します。

大きなファイルや多数セッションの同時利用はホストの資源を消費します。無制限な負荷への耐性や本番業務用のアクセス制御は対象外です。ブラウザを閉じるだけではサーバー上のセッションメモリが即時消去されるとは限りません。
